# Licence — reference caches

The JSON files in this directory are a slim, machine-readable index distilled
from the **System Reference Document** content that ships with the
[dnd5e system for FoundryVTT](https://github.com/foundryvtt/dnd5e). They are
generated by `scripts/content/srd-cache.mjs` and should never be hand-edited.

## What is and is not cached here

**Cached:** creature name, stored stat fields (ability scores, hit points and
hit-dice formula, challenge rating, size, creature type, speeds, senses,
languages), and the *path* to each creature's token image.

**Not cached:** descriptive text, trait and action prose, or any image bytes.

The token art these files reference is mostly NOT present: measured on a real
install, 0 of 346 SRD 5.1 creatures and only 14 of 431 SRD 5.2 creatures have
usable art, with a further 34 pointing into the paid `dnd-monster-manual`
module. What art does exist ships with the dnd5e system and stays where
the system installed it. `srd-cache.mjs --art` copies it into a vault purely so
Obsidian can render a statblock card locally. The dnd5e system credits that art
to [Forgotten Adventures](https://www.forgotten-adventures.net/) — check their
terms before redistributing it anywhere.

This directory is a build artifact of a licensed local install. Regenerate it
rather than editing it, and do not treat it as a redistribution channel for
anything beyond the SRD fields listed above.

## Open5e indexes (`open5e-2014.json`, `open5e-2024.json`)

Generated by `scripts/content/open5e-cache.mjs` from the
[open5e-api](https://github.com/open5e/open5e-api) repository's published
fixtures, under `data/v2/wizards-of-the-coast/srd-{2014,2024}/`. Both are the
same SRD content, under the same **CC-BY-4.0** licence as above — SRD 5.1 for
the 2014 rules and SRD 5.2 for the 2024 rules.

Attribution for the aggregation itself goes to the Open5e project, whose data is
likewise CC-BY-4.0: <https://github.com/open5e/open5e-api>.

**Cached:** creature name, armour class (and its short descriptor), hit points
and hit dice, challenge rating, size, creature type, ability scores, saving
throw and skill bonuses, speeds, senses, and the languages line.

**Not cached:** descriptive text, trait and action prose, or any imagery — the
source carries none. Open5e ships no artwork, so it cannot inform art selection;
that comes from the dnd5e system's own token art and your own files.

These files exist so stat blocks can be checked without network access, and are
regenerated by command rather than edited.
